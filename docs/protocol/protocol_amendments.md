# Protocol amendments

Each entry: date-time, what changed, why, and whether any outcome results had been seen when the change was made.

## Amendment 1 — 2026-11-25 (after data audit; after first US-W discovery estimates had been seen)
- **Sample weeks.** HHS collection weeks start on Sunday, not Friday. Window is 2020-08-02 to 2024-04-21 (195 weeks). No effect on specifications.
- **County covariates.** The Census API now requires a key. ACS variables replaced by SAIPE 2019 (income, poverty), Census PEP 2019 (population, age shares) and CDC PLACES (COPD, asthma, smoking prevalence; PLACES is the 2023 release, so it is not strictly predetermined and is used only in robustness interactions).
- **Holiday control** dropped: absorbed by division × week fixed effects.
- **Daily context.** The state-day context US-D is replaced by a facility-day context, **QC-D: Quebec emergency departments**, because the audit found hourly stretcher-occupancy data for 115 EDs (2022-10-24 onward). The data are the official MSSS hourly file as archived hourly by a third-party public git repository; MSSS itself publishes no history. Outcomes (fixed before opening the outcome series): daily mean stretcher occupancy rate (occupied / functional stretchers, %), daily mean patients on stretcher > 24 h, and (from 2023-02) daily mean patients present and patients waiting to be seen. Exposure: daily smoke PM2.5 from NAPS monitors and HMS plumes, built as in §5; HMS heavy-plume indicator as the alternative. Prior experience: HMS heavy-plume days 2010–2019 at the ED location (standardised). Specification: ED FE + date FE + region × month FE, same-day and lags 1–7, SEs clustered by health region (RSS) and date; with only ~16 regions, wild-cluster or date-clustered SEs are reported alongside. All of 2023 falls in one smoke season, so QC-D has no separate confirmation sample and is classified exploratory in advance.
- **Other audited contexts not analysed in this round** (data downloaded, linkage to smoke exposure not built): Chile DEIS daily ED visits by cause and establishment (no smoke exposure source verified), New York HERDS facility-day beds (column definitions ambiguous across two files), Alberta HQCA monthly (16 hospitals), California HCAI monthly, Portugal SNS monthly. They are scored on data criteria only.
- **Permutation placebo** reduced from 500 to 200 draws and run for P1 only (computing limits).

## Amendment 2 — 2026-11-25 (after econometric results; before any US forecast result had been seen)
- **Forecasting sample.** Full-sample walk-forward forecasting was stopped twice by the operating system for lack of memory (8 GB machine). All US forecasting runs therefore use a fixed random sample of 1,000 hospitals (seed in `config.py`). Hyperparameters were tuned earlier on the full pre-2023 sample (8 random configurations per learner on one chronological split, instead of 20 with walk-forward tuning). Tier-2 learners train on at most 100,000 rows; SVR on 12,000. Regressions are unaffected.
